# Эмулятор оболочки UNIX

Учебный эмулятор командной строки с графическим интерфейсом (tkinter)
и виртуальной файловой системой (VFS), которая целиком хранится
в памяти.

## Функции

- команды `ls`, `cd`, `du`, `uniq`, `exit` (описаны ниже);
- приглашение показывает текущую папку VFS (`/home/user$`);
- раскрытие переменных окружения реальной ОС (`$HOME`);
- кавычки в аргументах (`ls "my dir"`);
- комментарии: всё после `#` вне кавычек игнорируется;
- загрузка VFS из CSV-файла;
- обработка ошибок: неизвестная команда, незакрытая кавычка, ошибки
  стартового скрипта и загрузки VFS.

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | путь к физическому расположению VFS (CSV-файл) |
| `--script ПУТЬ` | путь к стартовому скрипту |

При запуске все заданные параметры выводятся в окно в виде отладочных
строк `[debug] ...`. Заголовок окна содержит имя VFS (имя файла из
`--vfs`, а без параметра — `vfs`).

## Формат VFS

VFS задаётся CSV-файлом в кодировке UTF-8 с заголовком
`path,type,content`:

| Колонка | Описание |
|---|---|
| `path` | абсолютный путь узла (`/home/user/a.txt`) |
| `type` | `dir` — папка, `file` — файл |
| `content` | содержимое файла в base64 (для папки пусто) |

Вложенность задаётся полным путём, поэтому дерево любой глубины
хранится плоским списком. Родительская папка каждого узла должна
присутствовать в файле, порядок строк не важен. Корневая строка
`/,dir,` необязательна. Двоичные файлы хранятся в base64 так же, как
текстовые.

```csv
path,type,content
/,dir,
/docs,dir,
/docs/c.txt,file,dGhpcmQK
```

Все операции выполняются в памяти: данные VFS на диск не
распаковываются и файл CSV не изменяется.

Ошибки загрузки (файл не найден, неверный заголовок, неверное число
колонок, неизвестный тип, неверный base64, нет родительской папки)
выводятся как `vfs error: ...` с номером строки, эмулятор при этом
продолжает работу с пустой VFS.

Образцы в папке `vfs/`: `minimal.csv` (только корень), `files.csv`
(несколько файлов), `deep.csv` (5 уровней вложенности, двоичный
файл), а в `vfs/invalid/` — файлы с ошибками.

## Стартовый скрипт

Текстовый файл в кодировке UTF-8: одна команда эмулятора в строке.
Комментарии начинаются с `#` (как в Python), пустые строки
пропускаются. При выполнении в окне показываются и ввод, и вывод, как
в диалоге с пользователем. Ошибка в строке скрипта выводится в виде
`script error (line N): ...`, выполнение остальных строк продолжается.
Если файл скрипта не найден или не читается, выводится
`script error: cannot read ...`, после чего эмулятор остаётся в
интерактивном режиме. Команда `exit` в скрипте закрывает окно.

## Команды

Пути могут быть абсолютными (`/home/user`) и относительными, поддержаны
`.` и `..` (выше корня подняться нельзя). Флаги из одной буквы можно
объединять (`ls -la`), `--` заканчивает флаги.

| Команда | Описание |
|---|---|
| `ls [-l] [-a] [путь...]` | содержимое папки или сведения о файле; `-l` — тип, размер и имя, `-a` — скрытые файлы (имя с точки); для нескольких путей выводятся заголовки |
| `cd [путь]` | сменить текущую папку; без пути — в корень `/` |
| `du [-s] [-h] [-a] [путь...]` | размер в байтах: по умолчанию для каждой вложенной папки и итог; `-s` — только итог, `-h` — вид 1.5K, `-a` — включая файлы |
| `uniq [-c] [-d] [-u] [-i] файл` | убрать соседние повторы строк файла из VFS; `-c` — счётчик, `-d` — только повторяющиеся, `-u` — только уникальные, `-i` — без учёта регистра |
| `exit` | закрыть эмулятор |

Ошибки (нет пути, это не папка, неверный флаг, лишние аргументы,
двоичный файл в `uniq` и т. д.) выводятся как `команда: сообщение` и
не прерывают работу.

## Запуск и тесты

```bash
make run
make run ARGS="--vfs vfs/deep.csv --script scripts/startup_stage4.txt"
make test
```

Или напрямую: `python3 -m src.main --vfs vfs/files.csv`.

## Скрипты запуска

В папке `scripts/` лежат скрипты для macOS/Linux (`.sh`) и Windows
(`.bat`), которые запускают эмулятор с разными параметрами:

| Скрипт | Что проверяет |
|---|---|
| `run_no_args` | запуск без параметров |
| `run_vfs_only` | только `--vfs` |
| `run_script_only` | только `--script` |
| `run_full` | оба параметра |
| `run_script_errors` | скрипт с ошибками в строках |
| `run_missing_script` | несуществующий файл скрипта |
| `run_script_exit` | команда `exit` в скрипте |
| `run_vfs_minimal` | минимальная VFS |
| `run_vfs_files` | VFS с несколькими файлами |
| `run_vfs_deep` | VFS с 5 уровнями вложенности |
| `run_vfs_missing` | ошибка: файл VFS не найден |
| `run_vfs_bad_header` | ошибка: неверный заголовок CSV |
| `run_vfs_bad_type` | ошибка: неизвестный тип узла |
| `run_vfs_no_parent` | ошибка: нет родительской папки |
| `run_stage4` | все команды этапа 4 с VFS и ошибками |

Стартовые скрипты эмулятора: `startup_demo.txt`, `startup_errors.txt`,
`startup_exit.txt`, `startup_stage3.txt` (этапы 1–3 с VFS и ошибками)
и `startup_stage4.txt` (все режимы `ls`, `cd`, `du`, `uniq` с ошибками).

## Структура

- `src/parser.py` — разбор строки, переменные окружения, комментарии;
- `src/commands.py` — реестр команд и их запуск;
- `src/cmd_fs.py` — команды `ls`, `cd`, `du`;
- `src/cmd_text.py` — команда `uniq`;
- `src/options.py` — разбор флагов команд;
- `src/config.py` — параметры командной строки;
- `src/script.py` — чтение стартового скрипта;
- `src/vfs.py` — дерево VFS в памяти;
- `src/vfs_loader.py` — загрузка VFS из CSV;
- `src/errors.py` — исключения;
- `src/gui.py` — окно приложения;
- `src/main.py` — точка входа;
- `tests/` — модульные тесты;
- `vfs/` — образцы VFS.

## Примеры

```
$ ./scripts/run_stage4.sh
[vfs] загружено узлов: 14
/$ ls -l /home/user
d       35 docs
-       46 notes.txt
/$ cd /home/user/docs
/home/user/docs$ du /home/user/docs
23	/home/user/docs/work
35	/home/user/docs
/home/user/docs$ uniq -c /home/user/notes.txt
      2 apple
      1 banana
      1 apple
      1 Cherry
      2 cherry
/home/user/docs$ cd /nope
script error (line 25): cd: /nope: No such file or directory

$ ./scripts/run_vfs_missing.sh
vfs error: vfs/no_such.csv: No such file or directory
```
